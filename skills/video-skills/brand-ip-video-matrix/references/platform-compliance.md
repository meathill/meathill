# 投放平台合规与品牌安全

这条流水线产出的是要挂到 TikTok / Reels / Shorts 上花钱投放的素材，
以下约束与"内容好不好"无关，但漏掉会直接导致限流、下架或法务风险。

## 一、AI 生成内容披露

- 多数平台要求对 AI 生成的**逼真内容**做标注。风格化卡通角色通常不触发逼真内容标注，
  但**真人皮肤、真实人物**必须标。
- 成片文件命名与描述里注明 `AI-generated character (CGI)`。
- Meta 会对疑似 AI 内容自动打标，TikTok 要求逼真 AIGC 主动标注。
- 需要更完整的溯源时，用 C2PA Content Credentials 写入元数据（可选）。

## 二、广告与商业合作标注

- 发布时开启平台的"品牌内容 / 付费合作"开关，caption 首行加 `#ad` 或 `Paid Partnership`。
- 不要做成"伪素人测评"外观——未标广告的商单会被限流或下架。
- 商业账号不要用热门音乐：平台对商业号的热门音乐有静音和限流政策，
  只用商业授权曲库（如 TikTok Commercial Music Library）并保存授权证据。

## 三、宣称与比较级

| 表述类型 | 风险 | 处理 |
|---|---|---|
| 比较级（`20x more powerful`、`up to X% more`） | FTC 要求有可比基准 | 没有基准报告就不说；有就带上比较对象 |
| 零售商 logo（Trusted By: Nordstrom…） | 上架 ≠ 背书 | 改成 `As seen at Nordstrom, Erewhon…` |
| 明星 / 医生 / 权威机构引用 | 暗示背书、需本人书面授权 | 未拿到授权文件不进成片 |
| 竞品对比（`0 Calcium Sulfite`、点名品牌） | 贬损性宣称 | 只讲自己是什么，不点名竞品 |
| "美国首家 / 第一"类排名 | 需要第三方研究的方法学与名称 | 拿不到就降级为不带排名的表述 |

## 四、字幕与免责

- 观众常常静音观看，**关键限定词必须也出现在字幕里**，不能只靠旁白说。
  `up to`、临床研究的样本量、第三方实验室、`±6% efficacy fluctuation`、
  `when used and replaced as directed` 这些都要能独立成立。
- 字幕底边距要留在平台 UI 之上：竖版顶部留约 220px、底部留约 320px、
  右侧留约 180px；关键产品不要压在右下角按钮区。
- 尾卡（品牌板）建议留 4.5s 静帧，把口径与免责小字放进去，给观众读完的时间。

## 五、安全区与素材一致性

- 平台 UI 会吃掉画面下沿。字幕中心放在画面高度约 77% 处既不被压住，
  又不挡住通常在画面中上部的角色。
- 字幕用 PIL 渲染 PNG 再 overlay 后，务必确认像素格式是 yuv420p——
  rgba 的 PNG 进 overlay 会把画面顶成 yuv444p，部分平台转码后偏色。

## 六、多平台转码

- 交付母版用 H.264 High / CRF 18 / yuv420p / faststart，单文件控制在 250MB 内。
- 不要用 ProRes 母版直接上传，二次压缩后字幕发虚、出现色带。
- 每个平台的字幕样式不同（字体、位置、安全区），
  用同一份 1080×1920 母版分别导出，不要在平台端再调字幕。
