# 上传材料

视频处理完后，用户通常还要写**标题、标签、简介、粉丝动态、封面 prompt**。这部分基于 SRT 转写的实际内容生成，比纯靠用户口述准得多。

## 时间戳换算

SRT 里的时间是**原片时间**，要换算到**成片时间**。

公式：成片时间 = 原片时间 - 裁掉的片头长度

例：片头裁了 622 秒（10:22）。原片 22:54 在成片里 = 22:54 - 10:22 = 12:32。

如果中间还裁了片段，要减得更多。简单的写法：累加每个被裁段的长度。

## 标题（B 站 / YouTube 通用）

给 3 个备选，覆盖三种调性：

1. **叙事感**：用一个引子勾住老粉。例："停了半年终于回归 | 聊聊 X 和 Y"
2. **干货向**：直击关键词，对推荐流和搜索友好。例："X × Y：一次讲清 Z"
3. **数字/疑问**：制造好奇心。例："X 到底有没有 10 倍效率？"

B 站标题 ≤ 80 字符，YouTube ≤ 100。**建议在前 30 字符内放最重要的关键词**，因为预览里会被截断。

## 标签（B 站 ≤ 10 个，每个 ≤ 12 字）

策略：

1. **第一个标签放主搜索词**——B 站搜索权重对第一个标签最高
2. **覆盖主题词 + 工具词 + 范畴词**：例如"AI 编程 / Claude Code / WebCoding / 程序员日常 / 直播回放"
3. **带话题的关注词**——B 站正在推什么话题，跟一波

## 简介（带时间戳章节最佳）

模板：

```
[一句话背景或心情]
[一句话主题概括]

如果觉得有用，三连 + 关注，下次把 X 讲完。

— 章节 —
00:00  开场 / [简短说明]
12:32  [话题1的精炼表达]
38:12  [话题2]
46:24  [话题3]
1:01:38  [话题4]
1:06:10  收尾 / [下次预告]

—
[补充说明：未剪原片在哪 / 相关链接 / 致谢]
```

时间戳跳转规则：

- B 站：写 `MM:SS` 或 `HH:MM:SS`，会自动变成跳转链接
- YouTube：同上，但需要 0:00 那行从开头开始
- 小宇宙：写 SHOWNOTES 区域

## 粉丝动态（B 站独有，≤ 233 字）

这是上传完成时推到关注者首页的文案。前两行最关键。

三种语气：

1. **叙事/怀旧**：适合老粉。"停了半年终于补上一场..."
2. **干货列表**：适合搜索/推荐流。用 ▸ 列要点
3. **互动鼓励**：适合鼓励评论。多用第二人称

字数计算：中文 1 字 1 char，emoji 1 字 1 char。

## 封面 AI prompt

用户通常用 ChatGPT / GPT-5 / Midjourney 画封面。

### 关键原则

- **不要让 AI 画文字**——中文几乎必错，英文也常错。让 AI 画**无文字背景**，文字用 Figma / Keynote 自己加
- **明确比例 16:9**（默认 1:1 不能用作 B 站封面）
- **指定留白区域**给后期加标题
- **风格定锚到具体参考**（Linear / Vercel / Pixiv 高赞，等）比形容词管用得多

### 模板 A：极客科技风（无人物）

```
请为我设计一张 B 站直播回放视频的封面图。

主题：[填具体主题]
风格：现代极客科技风，深色背景，霓虹光晕点缀
比例：16:9（1920×1080）
气质参考：Linear / Vercel / Anthropic 的视觉调性

画面内容：
- 主体：[填核心元素，例如"一台 MacBook 屏幕从侧面打开，
  屏幕里是流动的代码光线"]
- [填 1-2 个辅助元素]
- 背景：[填颜色/氛围]
- 留出右侧 1/3 的空白区域，方便后期加中文标题

绝对不要：
- 不要在图里写任何文字（中英文都不要）
- 不要写 logo、品牌名、网址
- 不要塞进多个人脸或卡通角色
- 不要过曝、不要彩虹色乱炖

输出：高分辨率、构图留白合理、可商用素材风格。
```

### 模板 B：人物插画风（B 站点击率更高）

```
请为我设计一张 B 站直播回放视频的封面图。

主题：[填具体主题]
风格：日系赛博朋克插画 / Pixiv 高赞作品调性，半写实半二次元
比例：16:9

画面：
- 主体：[填人物外观，例如"一位戴黑框眼镜的中国男程序员（25-35 岁），
  休闲卫衣，专注地看屏幕"]
- 屏幕中浮现出 [填主题相关的视觉元素]
- 桌面 [填 1-2 个生活化细节]
- 背景：[填环境]
- 整体氛围：[沉浸/孤独/专注/有故事，挑 2-3 个]

不要：
- 任何文字（中英文都别加）
- 多个角色
- 过度卡通化的大眼睛
- [其他不想要的元素]

构图：人物略偏左，右上方留 1/3 空间放标题。
高质量插画，光影细腻。
```

### 后期加文字的建议

- 主标题用 **粗黑/思源黑/苹方 Bold**，颜色与背景强对比
- 加一个**亮色块**（红/黄/橙）做强调词背景
- B 站封面**字号要大**：主标题 80-120 px（在 1146×717 的封面上）
- 给文字加描边或外发光，避免被画面背景吞掉

## 多平台联动（可选）

如果用户要发到多个平台，提醒他们：

| 平台 | 标题字数 | 封面比例 | 备注 |
|---|---|---|---|
| B 站 | ≤ 80 | 16:9 | 三连/关注引导 |
| YouTube | ≤ 100 | 16:9 | end screen 引导订阅 |
| 小红书 | ≤ 20 + emoji | 3:4 / 1:1 | 标题做前 4 字钩子 |
| 公众号 | ≤ 64 | 2.35:1 头图 | SEO 关键词在标题 |
| 即刻 | ≤ 不限 | 1:1 | 文字内容是主体 |
| 小宇宙 | ≤ 30 | 1:1 | SHOWNOTES 章节关键 |

每个平台**重写一遍**比直接复制效果好得多——同样的内容用不同的钩子和长度可以触达不同人群。
