# SEO 审计报告模板

使用本模板生成 Markdown 报告。按实际证据删减空段，但不要删除覆盖矩阵里的工具列；没有数据要写明原因，不要留空让读者误认为是 0。

## 标题和范围

```markdown
# 全站 SEO 审计报告

观察日：YYYY-MM-DD（Asia/Shanghai）
数据读取时间：YYYY-MM-DD HH:mm
审计模式：完整审计 / 关键词研究 / Issue 同步
```

说明：

- 纳入的网站、生产域名、对应仓库。
- 永久排除和本轮追加排除；说明“历史采集但当前不纳入”的数据如何处理。
- 是否包含额外发现的生产域名。
- 本轮只读边界，以及用户额外授权的 GitHub issue 写入边界。

## 结论摘要

用 3–8 条按优先级写：阻断问题、最大 CTR 机会、最大排名机会、最值得扩展的关键词/内容集群、最重要的数据缺口。每条引用问题 ID 和网站，不要把猜测写成事实。

## 跨站优先级

| ID | 优先级 | 证据状态 | 网站/URL | 问题 | 业务影响 | 下一步 |
|---|---|---|---|---|---|---|
| SEO-P1-001 | P1 | 已验证 | example.com/ | … | … | … |

严重度含义：P0=访问或收录阻断；P1=明显流量/转化损失或高价值机会；P2=重要质量/排名/归因问题；P3=低优先级或需观察。

| 网站 | 关键词族/意图 | Query | 点击 | 展现 | CTR | 平均位置 | 目标页面 | 判断/动作 | 状态 |
|---|---|---|---:|---:|---:|---:|---|---|---|

## Bing 关键词总结

单独记录 Bing 的实际窗口和页面汇总。UI 的“数据准备中”不是 0；取代表词时说明排序方式（如按展现）。

| 网站 | Query | 点击 | 展现 | CTR | 平均位置 | Bing 窗口 | 目标页面/内容方向 | 状态 |
|---|---|---:|---:|---:|---:|---|---|---|

## Google Trends 研究

记录地区、搜索类型、时间范围和比较组。相关/上升词只是选题线索。

| 主题组 | Query | 地区/类型 | 时间范围 | 平均相对热度 | 最近值 | 峰值/日期 | 相关上升词 | 可执行结论 | 置信度 |
|---|---|---|---|---:|---:|---|---|---|---|

明确写：指数经过归一化，不能解释为绝对搜索量、点击量、市场规模或流量预测。

## GA4、性能和 Ahrefs 证据

分别写自然入口页、sessions/users/engagement/key events；PageSpeed/Chrome 的字段和实验室；Ahrefs 的项目快照、关键词、Top pages、反链和引荐域。不要将不同工具的数字相加。

## 网站—账号—源码覆盖矩阵

| 网站 | 正式 URL | 仓库 | 源码 | 线上 | GSC | Bing | GA4 | PageSpeed/trace | Ahrefs | 主要结论 |
|---|---|---|---|---|---|---|---|---|---|---|

用 `✓`、`不可用`、`属性可见/指标未稳定读取`、`未发现` 等清晰状态。`未发现` 不等于 `0`。

## 详细问题

每条问题包含：

```markdown
### SEO-P1-001 — 简短问题标题

- 严重度：P1
- 证据状态：已验证 / 推断 / 待复核 / 数据不可用
- 网站/URL：
- 证据来源与观察窗口：
- 源码位置：绝对路径:行号，或源码不可用
- 业务影响：
- 修复/验证建议：
- 验收标准：
- 置信度：高 / 中 / 低
```

## 共享代码矩阵

同一个实现问题只写一个问题 ID，再列出受影响站点、源码位置和回归 URL；不要为每个站点复制相同问题。

## 访问缺口与证据边界

单独记录：源码缺失、属性/账号缺失、登录状态不足、工具配额、线上 SSL/超时、指标切换延迟、raw HTML 与渲染 DOM 的差异、Ahrefs 旧快照、Trends 低量样本。说明这些缺口阻止了哪些结论。

## Issue 同步结果（如适用）

| 仓库 | 操作 | Issue | 变化 | 验证 |
|---|---|---|---|---|
| owner/repo | 更新评论 / 新建 | #N | … | 回读成功 |

## 方法说明和只读验收

说明：工具优先级、实际时间范围、指标定义、重点 URL 选择方式、关键词分组逻辑、严重度规则、趋势数据限制和数据延迟。最后明确是否修改了源码、部署、sitemap、robots、索引设置、工具项目或爬虫配置。
