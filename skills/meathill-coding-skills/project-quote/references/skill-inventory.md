# 技能清单

> 本清单工时为 AI 辅助后的编码基线（传统经验工时 ×0.1），无需再次折算。范围由旧 ×0.25 基线统一乘以 0.4，并按 0.5 小时取整。

## 技术偏好与已验证能力

- 默认语言与工具：TypeScript、Node.js 24+、pnpm、Biome、自动化测试。
- Web 优先 Next.js + OpenNext；边缘 API 优先 Hono + Cloudflare Workers。
- 熟悉多 Web Worker、Queue producer、独立 Node.js Queue consumer 和多个计算 Worker 并行处理长任务。
- 熟悉 D1、KV、R2、Durable Objects、Service Bindings、定时/统计 Worker 和共享 migration。
- 熟悉任务重试、错误分类、孤儿任务补发、队列积压告警、进程心跳、Sweeper、状态回调和可观测性。
- 复杂的 Web + 多 Worker + Queue 架构属于已有经验，不增加首次使用风险；仍按实际组件和业务复杂度计入编码量。
- 预算紧张时优先复用存量系统，并用以上熟悉技术补充新组件，不为了形式统一强行迁移平台。

## 调整因子
- 首次使用某技术：+30-50%
- 紧急交付：+20-30%
- 需求不明确：+20-40%
- 多语言/多时区：将翻译、排版和人工验收计入辅助工时，不对全部编码统一加成
